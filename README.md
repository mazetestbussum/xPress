## xPress Automated Website Generation
This pipeline uses
 * Tally.so for client wishes acquisition;
 * Codex with ui-ux-pro-max for structuring and sitemapping;
 * A set of blank Wordpress templates in Github;
 * Codex for compiling pages and tailored copywriting;
 * A human-in-the-loop step for QA in Github; and
 * Vimexx for hosting.
